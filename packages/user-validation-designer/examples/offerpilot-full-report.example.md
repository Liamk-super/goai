# OfferPilot｜用户验证完备版

> **用户需求：偏弱**　**证据可信度：中**
> 需求存在，但当前切换或持续使用动力不够强，先解决最影响复用的问题。

## 1. 核心结论与目标用户
- **核心用户：** 收到或等待面试通知，只有几天准备时间，需要面试前快速做几轮针对性练习的人
- **可争取：** 已经在用ChatGPT + 免费面经，但仍想要更好结果的人
- **暂不优先：** 当前不够紧迫，且师兄模拟 + 网上面试题基本够用的人
- **总判断：** 当前最值得争取的是收到或等待面试通知，只有几天准备时间，需要面试前快速做几轮针对性练习的人群，而不是所有目标用户。
- **最大问题：** 产品还没有证明自己比现有替代方案明显更好

## 2. 用户画像与使用场景
### 1. 秋招冲刺期、近期有面试的学生
- **典型场景：** 收到或等待面试通知，只有几天准备时间
- **核心目标：** 面试前快速做几轮针对性练习
- **当前替代：** 牛客面经 + 同学互练
- **为什么会用：** 面试时间临近，希望低成本发现回答问题
- **为什么可能不用：** 评价如果继续像通用模板，就没有再次使用的理由
- **切换判断：** 仍需验证
### 2. 准备暑期实习、仍在比较替代方案的学生
- **典型场景：** 实习招聘开始，想先练一次看看效果
- **核心目标：** 先熟悉面试流程和常见问题
- **当前替代：** ChatGPT + 免费面经
- **为什么会用：** 希望比通用面经更针对自己的简历
- **为什么可能不用：** ChatGPT 和免费面经已经够用，产品差异不明显时不会切换
- **切换判断：** 仍需验证
### 3. 学术背景转工业界的研究生
- **典型场景：** 准备工业界岗位，需要练项目追问
- **核心目标：** 把学术项目讲成工业界面试能理解的回答
- **当前替代：** 师兄模拟 + 网上面试题
- **为什么会用：** 需要产品真正理解简历中的论文和项目
- **为什么可能不用：** 师兄可以免费帮忙，时间不紧时不会优先换工具
- **切换判断：** 仍需验证

## 3. 关键证据与判断依据
- **产品后台数据：** 注册 420→上传简历 286→开始面试 231→完成面试 168→30 天内第二次使用 63→3 次以上 37
- **真实用户访谈：** 用户反馈第一次使用有新鲜感，但评价容易像套模板；希望围绕简历项目深入追问；有用户等待时以为卡住；也有用户只在面试密集期考虑购买。

## 4. 当前最关键的用户问题
### 问题 1：反馈过于通用
- **发现依据：** 面试评价多次出现相似的通用建议，用户认为像套模板
- **为什么重要：** 用户看不到针对自己的价值，就很难形成再次使用理由。
- **建议：** 让报告引用本次回答，指出问题、原因和改写示例；验证“建议太泛”的反馈是否下降。
### 问题 2：个性化追问还不够深
- **发现依据：** AI 追问没有充分围绕简历项目和目标岗位深入展开
- **为什么重要：** 如果和通用 AI 差别不明显，用户没有切换理由。
- **建议：** 让每轮追问都引用具体经历或目标要求；验证用户是否明显觉得比通用 AI 更针对。
### 问题 3：等待过程缺少明确反馈
- **发现依据：** 生成问题等待时间较长，有用户一度以为页面卡住
- **为什么重要：** 关键路径的不确定感会直接制造中途流失。
- **建议：** 补充明确进度和等待反馈；验证关键路径中途放弃是否下降。
