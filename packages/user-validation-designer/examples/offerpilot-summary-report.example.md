# OfferPilot｜用户验证

> **用户需求：偏弱**　**证据可信度：中**
> 需求存在，但当前切换或持续使用动力不够强，先解决最影响复用的问题。

## 1. 一眼看懂
- **核心用户：** 收到或等待面试通知，只有几天准备时间，需要面试前快速做几轮针对性练习的人
- **可争取：** 已经在用ChatGPT + 免费面经，但仍想要更好结果的人
- **暂不优先：** 当前不够紧迫，且师兄模拟 + 网上面试题基本够用的人
- **为什么会用：** 面试时间临近，希望低成本发现回答问题
- **为什么不用：** ChatGPT 和免费面经已经够用，产品差异不明显时不会切换
- **最大问题：** 产品还没有证明自己比现有替代方案明显更好

## 2. 当前最关键的问题
1. **反馈过于通用**：用户看不到针对自己的价值，就很难形成再次使用理由。
2. **个性化追问还不够深**：如果和通用 AI 差别不明显，用户没有切换理由。
3. **等待过程缺少明确反馈**：关键路径的不确定感会直接制造中途流失。

## 3. 下一版先改什么
- **P0**｜让报告引用本次回答，指出问题、原因和改写示例；验证“建议太泛”的反馈是否下降。
- **P0**｜让每轮追问都引用具体经历或目标要求；验证用户是否明显觉得比通用 AI 更针对。
- **P1**｜补充明确进度和等待反馈；验证关键路径中途放弃是否下降。

## 4. 为什么这么判断
| 维度 | 判断 | 依据 |
|---|---|---|
| 用户需求 | 中 | 面试临近时需求明显，但并非所有求职学生都有… |
| 使用频率 | 偏弱 | 更像面试通知触发的阶段性使用 |
| 痛点强度 | 中 | 通用面经不够针对，但仍有可接受替代 |
| 替代差距 | 偏弱 | ChatGPT、面经和真人帮助能解决部分需求 |
| 付费意愿 | 待验证 | 尚未通过正式收费入口验证真实付费行为 |
| 传播性 | 待验证 | 暂无可靠的自然推荐或分享行为证据 |
- **产品后台数据**：注册 420→上传简历 286→开始面试 231→完成面试 168→30 天内第二次使用 63→3 次以上 37
> **仍待确认：** 还缺统一口径的复用数据，持续使用判断仍需验证。

## 5. 下一步怎么验证
1. **更具体、针对本次回答的诊断能否提升用户再次使用**｜真实复用观察：上线新版诊断后，用同一口径比较完成首次后再次使用…｜看：新版上线后，再次使用率明显高于修改前基线
2. **流失主要来自 AI 反馈太泛，还是需求本身只在面试期出现**｜流失用户访谈：访谈完成过首次但没有继续使用的用户，记录他们主动…｜看：能够区分内容质量、低频需求和替代方案三类原因的主次
