# Human Report Presentation Layer V0.3

## 目标

V0.3 在 V0.2 的“结论 → 行动 → 依据”基础上，把 HTML 变成真正可折叠的立体报告：默认足够简洁，同时保留比赛、复盘和核查所需的完整人类可读依据。

## 三级阅读结构

1. **3–5 秒：结论层**
   - 核心用户 / 可争取用户 / 暂不优先；
   - 为什么会用 / 为什么不用 / 最大问题。
2. **30 秒：行动层**
   - Top 3 用户问题；
   - Top 3 下一版动作。
3. **主动展开：验证层**
   - 评分框架与关键依据；
   - 用户画像与使用场景；
   - 完整验证方案。

## HTML 默认结构

默认可见 4 个主块：

1. 一眼看懂；
2. 当前最关键的问题；
3. 下一版先改什么；
4. 想验证结论？展开详细分析。

深度层使用原生 `<details>/<summary>`，默认关闭，不依赖 JS。

## 第一屏视觉层级

三类目标用户不得使用同一颜色：

- 核心用户：青绿色；
- 可争取用户：蓝紫色；
- 暂不优先：暖橙色。

“为什么会用 / 为什么不用 / 最大问题”合并为单一 Decision Strip，用内部三段和分隔线表达，不再拆成三个同权重卡片。

## 深度层

### 评分框架与关键依据

保留六维判断、关键真实材料和待确认项，但隐藏内部计算与 Evidence 等级代码。

### 用户画像与使用场景

允许在用户主动展开后展示更具体的年级、职业等背景；字段限定为场景、目标、替代、动机、拒绝、切换判断和 Top 痛点。

### 完整验证方案

可展示方法、样本、周期、成本、任务和成功条件，用于比赛方案或复盘；内部 plan_id / evidence upgrade 等仍留在 Machine Output。

## 双格式输出

- `structured_output.human_report`：保持短 Markdown，用于快速阅读。
- `structured_output.human_report_html`：三级折叠式 HTML，既可快速阅读，也可展开作为比赛/复盘材料。

两者都由 `src/presentation.mjs` 从同一份已校验结构确定性渲染，不重新调用模型。

## 证据纪律

沿用 V0.2：模拟不冒充真实、30 天复用口径保守、未开放收费不把 0 付费判失败、未执行体验时不生成具体体验事实。
