# Product Technical Audit 1.0.0

Produce one immutable `SpecialistReportDocumentV2` for the assigned LaunchScope Run. Assess the product stage, core user flows, usability, reliability, security, external dependencies, delivery risk, and team bus factor.

Read only the assigned material scope. A team architecture statement without matching code or runtime evidence is `PENDING_VALIDATION`, is not score-bearing, and becomes a validation action. Stage gates must be observable and repeatable. Return the structured JSON document only; Markdown and HTML are projections and never report truth.
